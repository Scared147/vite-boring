关于这个项目

Node Boring 是一个用于学习和快速原型开发的 Node.js 基础项目模板。 它采用 Express 框架，将路由、静态文件服务与 HTML 页面分离， 提供一个干净、可扩展的起点。

无论你是刚开始学习 Node.js 后端开发，还是需要一个快速验证想法的脚手架， 这个项目都能帮助你节省初始搭建的时间。

快速开始

三步启动你的应用

1️⃣

安装依赖

在项目根目录执行 npm install 安装 Express 等依赖。

2️⃣

启动服务器

执行 npm start 启动服务，或使用 npm run dev 开启热重载。

3️⃣

开始开发

在 views/ 目录下修改页面，在 server.js 中添加新路由。
